# 共享单车使用需求分析

基于 **UCI Bike Sharing Dataset** 的探索性数据分析与统计建模项目。研究**什么因素影响共享单车需求、时间和天气的影响有多大**，为运营方的车辆调度与投放提供数据支撑。

## 项目背景

共享单车的核心运营难题是"在什么时间、什么地点投放多少车"。需求受天气、季节、工作日/节假日等多重因素影响。本项目对两年（2011–2012）日粒度骑行数据进行分析，量化这些因素的影响程度，并给出可落地的调度建议。

## 核心问题

- 什么因素驱动了单车需求？时间和天气的影响有多大？
- 天气好坏对需求的差异是否具有统计学显著性？
- 运营方应如何据此优化车辆调度？

## 数据集

- 来源：[UCI Bike Sharing Dataset](https://archive.ics.uci.edu/ml/datasets/Bike+Sharing+Dataset) 日粒度版本（`day.csv`，共 731 天）
- 核心字段：

| 字段 | 含义 |
|---|---|
| `season` | 季节（1=春, 2=夏, 3=秋, 4=冬） |
| `yr` | 年份（0=2011, 1=2012） |
| `mnth` / `weekday` | 月份 / 星期（0=周日 … 6=周六） |
| `holiday` / `workingday` | 是否节假日 / 是否工作日 |
| `weathersit` | 天气状况（1=晴, 2=阴/雾, 3=小雨雪, 4=暴雨雪） |
| `temp` / `atemp` | 归一化温度 / 归一化体感温度 |
| `hum` / `windspeed` | 归一化湿度 / 归一化风速 |
| `casual` / `registered` | 临时用户 / 注册用户租车量 |
| `cnt` | 总租车量（目标变量） |

## 分析流程

1. **数据清洗**：检查缺失值与重复值（数据完整，无需额外处理）
2. **探索性分析（EDA）**
   - 逐月总量时序图（2011 vs 2012）
   - 分季节箱线图
   - 工作日 vs 节假日的用车量均值对比
   - 不同天气状况下的用车量均值对比
3. **相关性分析 + 统计检验**
   - `cnt` 与温度 / 湿度 / 风速的散点图、相关系数热力图
   - **t 检验**：晴天（`weathersit=1`）vs 非晴天（`weathersit=2,3`）的需求差异是否显著
4. **线性回归（OLS）**
   - 以天气、时间变量为特征、`cnt` 为目标拟合线性模型，分析各变量的系数与显著性

## 主要结论

1. 需求整体呈上升趋势，且具有**极其鲜明的季节性**
2. **气象条件是决定总需求的关键驱动因素**
3. 晴天与非晴天的需求差异具备**极强的统计学显著性**（p < 0.05）
4. 运营建议：收到暴雨预警时，优先回收休闲站点的车辆，保留地铁 / 办公区接驳站点的供给
